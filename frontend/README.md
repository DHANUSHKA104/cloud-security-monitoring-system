# CloudSec Monitor Frontend

React 18 + TypeScript + Vite + Tailwind CSS frontend application following the SentinelCore project specification and mentor folder layout.

## Development Scripts
- `npm run dev`: Launch Vite development server on port 5173
- `npm run build`: Compile TypeScript and build production bundle
- `npm run preview`: Preview production build
- `npm run test`: Run Vitest component and unit test suite
- `npm run lint`: Run ESLint code quality checks
